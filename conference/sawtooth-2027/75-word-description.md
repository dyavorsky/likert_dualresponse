# 75-word brochure description

Dual-response conjoint asks a binary follow-up question: "would you actually buy it?" We provide the behavioral model and likelihood for its natural extension to an ordinal follow-up: "how likely are you to buy it?" We compare our approach to two common shortcuts (collapsing the scale to yes/no via top-box, and assigning each scale point a fixed purchase probability) and show that both can bias profit expectations. R code provided.
