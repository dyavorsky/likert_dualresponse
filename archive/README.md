# Archive

Exploratory Python notebooks from the project's 2024 prototyping phase, kept
for provenance only. None reflect the current model: they predate Models A/B,
the cumulative-link formulation, and the cut-point parameterization. The live
implementation is the R code in `../R/` and the companion package at
`../../ordinalDualresponse`.

`example_discretechoice.ipynb` and `example_likert.ipynb` were published as
pages of the manuscript site until they were unpublished (they had not been
touched since 2024-07-01). See `../TODO.md` if example notebooks are wanted
back — the intent is R mirrors of the package vignettes.

These files are tracked normally. `sandbox/` remains in `.gitignore` for
genuine local scratch, which is why this directory is `archive/` instead.
